# Nocturne · Moonlit Garden

Open `index.html` through an HTTP server or GitHub Pages. No build step, paid API, package installation or account is required to play.

- Live development edition: https://yosinokouiti.github.io/nocturne-piano/dev/
- Existing edition: https://yosinokouiti.github.io/nocturne-piano/
- Architecture/research: `../docs/NOCTURNE_NEXT.md`
- Verification and current limits: `../docs/VALIDATION.md`
- Credits: `THIRD_PARTY_NOTICES.md`

The cat and world are original procedural 3D assets. Complete piano recordings are streamed from the CC0 Open Goldberg Variations release. Music needs an internet connection; the app contains all code and shaders locally.

Version 0.2 adds food/water, ball and feather-wand play, scratching, cushion rest, exploration and stretching. Use the care panel immediately beneath the garden.

Version 0.3 adds 25 public-domain orchestral tracks, two official anime video embeds, searchable categories and local-device audio playback. Orchestral recordings and device files feed the audio-reactive garden; official videos do not.
